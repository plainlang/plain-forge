# Task Manager (Python/Textual)

A terminal-based task manager app built with Python and Textual, letting you view, add, and delete tasks from a keyboard-driven TUI.

![Task Manager (Python/Textual)](python-taskmgr-textual.png)

# Prerequisites

The `pexpect` and `pyte` packages need to be installed for the example to run:

```bash
pip install pexpect pyte
```

# How to render the example

You can run the example with the `codeplain` command:

```bash
codeplain task-manager.plain
```

# How to run the generated code

After the rendering is finished, you can run the generated software code using the command:

```bash
python3 build/taskmgr.py
```

See [top-level README](../../README.md) for additional information and help for troubleshooting the examples.
